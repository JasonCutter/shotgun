## 기준 원칙
- AI 결과는 승인 전 후보다.
- Claim과 Fact를 구분한다.
- 모든 후보와 파생 결과는 Provenance를 가진다.
- 원본을 조용히 수정하거나 과거 결정을 덮어쓰지 않는다.
- Compiled Truth는 Canonical 기록에서 재생성되는 파생 투영이다.
- 중요 변경은 이유·대안·영향과 변경 이력을 남긴다.
