### 확정 결정
1. 초기 정식 지원 확장자는 다음과 같이 한다.
문서·웹 보관: .pdf, .docx, .txt, .md, .html, .htm, .mht, .mhtml
스프레드시트: .xlsx, .csv
프레젠테이션: .pptx
이미지: .png, .jpg, .jpeg, .webp
구조화 텍스트·설정: .json, .xml, .yaml, .yml
1. ‘제한 지원’ 등급은 두지 않는다. 정식 지원 목록에 없는 파일은 파일 선택 또는 제출 단계에서 거부하며, 업로드는 됐지만 처리 가능 여부가 불확실한 상태를 만들지 않는다.
2. 업로드 한도는 파일당 최대 50MB, 한 번의 제출당 최대 20개, 제출 총용량 최대 200MB로 한다.
3. 구형 Office 형식인 .doc, .xls, .ppt는 초기 지원에서 제외한다. 필요한 경우 사용자가 .docx, .xlsx, .pptx로 변환한 뒤 제출한다.
4. .rtf, .tsv, .gif, OpenDocument 형식, Apple 문서 형식, 압축 파일, 오디오·영상 파일, 실행 파일과 프로그램 바이너리는 지원 대상에서 제외한다. 압축·오디오·영상 파일은 장기 확장 범위로도 예약하지 않는다. 단, YouTube URL의 자막·스크립트 기반 처리는 Section 1.4의 URL 입력 범위로 유지한다.
5. 암호화되거나 암호가 설정된 파일은 업로드 대상으로 받지 않는다. 손상되거나 실제로 읽을 수 없는 파일은 Step 2 검증에서 거부한다. Shotgun은 파일 암호 입력, 해제 또는 복구 기능을 제공하지 않는다.
6. 파일 선택 버튼과 드래그 앤 드롭을 모두 지원한다. 복수 파일 선택을 지원하고, 제출 전에는 개별 파일을 제거할 수 있으며, 업로드 중에는 전체 업로드를 취소할 수 있다.
7. 여러 파일 중 문제가 있는 파일이 발견되면 해당 파일만 제외하고 나머지 정상 파일은 계속 진행한다. 문제 파일과 제외 사유는 사용자에게 명확히 표시한다.
### 결정 근거
초기 버전에서는 실제 사용 가능성이 높은 형식만 정식 지원하고, 접수 후 처리 실패가 예상되는 모호한 ‘제한 지원’ 상태를 제거한다. 단일 크기 정책은 설명과 구현이 단순하며, 문제 파일만 분리하는 부분 성공 방식은 정상 자료의 처리를 불필요하게 막지 않는다.
### 제외한 대안
구형 Office·OpenDocument·Apple 문서의 서버 변환, 폭넓은 파일 접수 후 사후 판정, 암호 입력과 파일 복구, 압축·오디오·영상 파일의 장기 확장 예약은 채택하지 않는다.
### 영향 범위와 후속 검토
확장자와 사용자 선택 허용 목록은 Section 1.2가 소유한다. 실제 형식·MIME·파일 시그니처, 확장자 위장, 손상 여부와 안전성은 Step 2에서 검증한다. 파일 콘텐츠 추출 성공 여부는 Step 4에서 다룬다. 여러 파일의 제출 묶음·부분 성공 상태와 결과 표시의 상세 계약은 Section 1.6에서 이 결정을 전제로 구체화한다.
### 미결사항
정책 수준의 미결사항은 없다. 오류 코드, MIME 허용 목록, 진행률 표시와 취소 시 정리 방식은 후속 기술 설계에서 확정한다.
