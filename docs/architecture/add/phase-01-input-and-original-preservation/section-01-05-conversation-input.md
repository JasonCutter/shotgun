회의 상태: 완료
결정일: 2026-07-13
### 확정 결정
1. AI 대화, 메신저 대화, 회의록, 인터뷰, 이메일 스레드, 공개 토론과 상담 기록은 지식·사실 자료가 아니라 의견·참고 자료로 취급한다.
2. 대화는 별도 입력 채널을 만들지 않고 파일·직접 텍스트·URL을 통해 들어오는 MaterialKind = CONVERSATION 자료 유형으로 유지한다.
3. 사용자가 제출한 대화 자료 전체를 하나의 Source Item으로 보존하며 제출된 원문 형태와 순서를 유지한다.
4. Message Unit 분해, 화자 식별·동일인 병합, 시간 정규화, 답글·스레드 관계 분석을 기본 처리로 수행하지 않는다.
5. 대화 자료에서 Claim, Fact, Entity, Relation, Event, Decision, Action 후보를 자동 추출하지 않으며 Canonical 지식이나 Compiled Truth에 자동 반영하지 않는다.
6. 대화 자료는 검색과 원문 재확인을 위한 의견·참고 자료로만 유지한다.
7. 대화 안의 첨부파일과 링크는 원문 참조로만 보존하고 자동 수집하지 않는다. 실제 자료가 필요하면 파일 또는 URL로 별도 제출한다.
8. 사용자가 특정 요약·정리·분석을 명시적으로 요청한 경우에만 일회성 파생 결과를 만들 수 있으며, 이 결과도 별도 승인 없이 Canonical 지식이 되지 않는다.
### 결정 근거
대화에는 사실, 오류, 추측, 설득, 아이디어와 개인 의견이 혼재한다. 이를 일반 문서와 같은 방식으로 자동 지식화하면 의견이 사실로 승격되거나 맥락에서 분리될 위험이 있다. 따라서 원문을 의견 자료로 보존하되 기본 지식 처리 파이프라인에는 투입하지 않는다.
### 제외한 대안
Message Unit 구조 생성, 화자·역할·시간·스레드 정규화, 화자와 Canonical Entity의 자동 연결, 지식 후보·결정·행동 항목 자동 추출, 메신저·메일 계정 실시간 동기화, 채널·워크스페이스·메일함 전체 수집은 채택하지 않는다.
### 영향 범위와 후속 검토
Step 3은 대화 자료의 원본 Source Item을 보존한다. Step 4\~7의 기본 추출·구조 분석·근거화·번역 파이프라인과 Phase 3의 지식 후보 생성은 대화 자료에 자동 적용하지 않는다. 대화 자료에 대한 요약·정리·분석 요청은 입력 단계가 아니라 Source Item 저장 이후의 활용·재처리 단계에서 다루며, 여러 대화 자료의 동시 제출은 Section 1.6에서 다룬다.
### 미결사항
Section 1.5의 정책 수준 미결사항은 없다.
