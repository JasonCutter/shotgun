## 상태
- 회의 상태: **완료**
- 범위: Section 1.1\~1.9
## 책임
사용자가 파일·직접 텍스트·URL과 대화 성격의 자료를 최소한의 입력 부담으로 제출하고, 각 항목이 독립적인 Source Item 후보로 접수되도록 입력 채널·범위·UI·상태·취소와 책임 경계를 정의한다.
