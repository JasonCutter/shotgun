## 결정 1 — 스캔 PDF·이미지 OCR을 어떻게 할까?
### 쉽게 말하면
글자가 이미지로 들어 있는 PDF나 사진은 일반 추출기로 읽을 수 없습니다. OCR을 사용하면 읽을 수 있지만, 외부 클라우드 OCR은 원문을 외부 서비스에 보내며 비용이 발생할 수 있습니다.
### A. 로컬 OCR 자동 + 외부 OCR은 항목별 허용 — 권장
- 내 컴퓨터 또는 Shotgun 서버에서 먼저 OCR합니다.
- 로컬 OCR 품질이 부족한 경우에만 사용자에게 외부 OCR 사용 여부를 묻습니다.
- 원문 외부 전송과 비용을 사용자가 통제할 수 있습니다.
- 단점: 표·복잡한 배치의 인식률이 클라우드보다 낮을 수 있습니다.
### B. 클라우드 OCR 자동 사용
- 인식 품질과 복잡한 문서 처리 가능성이 높습니다.
- 원문이 외부 서비스에 자동 전송되고 비용이 발생할 수 있습니다.
### C. 초기 버전에서는 OCR 제외
- 개인정보와 비용 문제가 가장 단순합니다.
- 스캔 PDF와 이미지 속 글자는 지식화하지 못합니다.
**권장 답변: A**

## 결정 2 — 외국어 자료의 한국어 번역을 언제 만들까?
### 쉽게 말하면
모든 외국어 문서를 처음부터 전부 번역하면 보기 편하지만 처리 시간·비용·저장량이 늘어납니다. 필요한 부분만 번역하면 효율적이지만 처음 열 때 잠시 기다릴 수 있습니다.
### A. 필요한 구간만 자동 번역하고 저장 — 권장
- 사용자가 보거나 AI가 한국어 표시를 필요로 하는 구간만 번역합니다.
- 번역 결과는 캐시해 다시 사용합니다.
- Phase 3 지식 후보 생성은 원문 근거로 계속 진행하므로 번역 실패가 전체 처리를 막지 않습니다.
- 외부 번역 서비스 사용은 별도 설정 또는 항목별 허용을 요구합니다.
### B. 모든 비한국어 자료를 접수 후 전체 자동 번역
- 자료를 열었을 때 바로 한국어로 볼 수 있습니다.
- 처리 시간·모델 비용·저장량이 가장 큽니다.
### C. 사용자가 번역 버튼을 누를 때만 생성
- 비용이 가장 적습니다.
- 한국어 중심 사용 경험이 끊기고 반복 요청이 늘어날 수 있습니다.
**권장 답변: A**
## 추가사항.
모든 자료는 입력을 받은 후 ai처리를 진행하느데 ai처리는 처리 요청을 모아서 batch로 한번에 처리한다. 자료 입력 후 즉시가 아니라 1주일치를 모아서 일요일 밤 특정 시간에 한번에 처리한다. 번역이고 이미지고 요약이고 뭐든.
