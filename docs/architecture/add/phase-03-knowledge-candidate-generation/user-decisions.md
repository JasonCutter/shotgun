## AI 추론 후보를 주간 Batch에서 자동 생성할 것인가
### 의미
원문에 직접 적힌 주장·사건·결정·할 일을 후보로 만드는 것은 직접 추출이다. 여러 근거를 조합해 원문에 그대로 쓰이지 않은 결론이나 관계를 만드는 것은 추론 후보다.

- `WeeklyAIBatch`는 원문에 명시된 후보만 자동 생성한다.
- 원문에 없는 결론·관계·예측은 사용자가 요청하거나 후속 Knowledge Discovery 단계에서만 만든다.
- 장점: 오류·잡음·비용과 검토 부담이 적고 원문 확인이 쉽다.
- 단점: 숨은 관계와 통찰의 발견이 늦어진다.
### B안 — 직접 후보와 추론 후보를 함께 자동 생성
- `WeeklyAIBatch`가 근거를 조합한 추론 후보도 자동 생성한다.
- 추론 후보는 직접 후보와 분리 표시한다.
- 장점: 숨은 관계·문제·가능성을 빠르게 발견한다.
- 단점: 후보 수, 비용, 검토 부담과 잘못된 추론 가능성이 증가한다.
## 공통 안전장치
어느 안이든 추론 후보는 Fact가 아니다. 사용한 근거·정책·도출 요약을 기록하고 Phase 4의 비교와 승인을 통과해야 한다.
