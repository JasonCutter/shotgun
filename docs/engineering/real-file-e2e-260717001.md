## Defects found and fixed

1. The text locator normalized trailing line breaks before trying an exact match. This changed the
   full-document range from 0–779 to 0–775 and caused Evidence creation to fail. Exact Unicode
   matching now runs first; whitespace-normalized matching remains a fallback.
2. Original Asset resolution compared Asset Reference objects with order-sensitive
   `JSON.stringify`. A semantically identical reference from another JSON client could therefore
   be rejected. Comparison now uses canonical stable JSON, with a property-reordering contract
   regression test.
