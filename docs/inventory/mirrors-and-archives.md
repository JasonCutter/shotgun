# Project Shotgun Mirrors and Archives

## Current authority

GitHub repository `JasonCutter/shotgun`, branch `main`, is the sole Canonical authority. Notion and Google Drive preserve readable mirrors, source provenance and historical records.

## Metadata standard

High-value external documents display:

```text
Canonical status
Canonical repository
Canonical path
Canonical revision
Last synchronized
```

Where a historical page contains an obsolete authority or status statement, the new banner explains that the body is retained as historical evidence and identifies the current Git authority.

## Archive standard

Archive classification does not delete the source. It records:

- historical role;
- current non-governing status;
- Canonical successor;
- archive date;
- preservation reason.
