# Standalone Lucas text locator consumer

Shotgun 애플리케이션·DB·AI SDK를 설치하지 않고
`@shotgun/lucas-text-locator@1.0.0` 하나만 사용하는 별도 예제 프로젝트다.

저장소에서는 다음 명령이 패키지를 tarball로 만든 뒤 임시 프로젝트에 설치하고 실행한다.

```bash
npm run test:stage12-package
```

출시 후에는 일반 패키지처럼 `npm install @shotgun/lucas-text-locator@1.0.0`으로 설치한다.
