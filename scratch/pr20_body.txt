## 2. 주요 구현 내용 (Key Implementation)

1. **소유권 경계 격리 (ADR-114)**:
   - `AuthRepository`: Principal, Session, Membership, API Token
   - `ProjectAdministrationRepository`: Project identity/metadata, status, capability, revision
   - `SettingsRepository`: Principal Preference, Project Policy, System/Resource Settings, Revisions, Command Execution

2. **계약 & 디코더 (`packages/contracts`)**:
   - 디코더 기반 fail-closed 검증 및 비가공 시크릿 노출 차단 가드 구현
   - `SettingDescriptor`, `SettingsSnapshot`, `ProjectListItemView`, `ModelDescriptorView`, `CostBudgetView`, `PrivacyRetentionView`, `ConnectorSettingsView`, `DirectiveProposalView`, `SchemaPackView`, `DiagnosticsView` 디코더 완성

3. **Domain Port, InMemory/Postgres Repository & DB Migration**:
   - `modules/project-administration`, `modules/settings-policy`
   - `adapters/settings-project-admin-in-memory`, `adapters/postgres`
   - `db/migrations/016_stage1_section2_settings_project_admin.sql` (`project_admin`, `settings` 스키마)

4. **Product REST API Endpoints (`assemblies/shotgun-app`)**:
   - `/api/v1/projects/*` & `/api/v1/settings/*` Fastify 라우트 핸들러 구현
   - `clientRequestId`, `idempotencyKey` 검증, CSRF 토큰 보호, expectedRevision 409 CONFLICT 충돌 처리

5. **Client, Draft Controller, Leave Guard & Frontend Workspaces (`apps/shotgun-web`)**:
   - `ShotgunApiClient` 5D 쿼리 키 구조 및 캐시 퍼지 로직 (`purgeSettingsScopedCaches`)
   - `SettingsDraftController` 상태 기계, draft command ID pinning, typed error 복구 및 Option B Leave Guard 통합 (`useLeaveGuard`)
   - Runtime decoder 연결 (`decodeSettingsSnapshot`, `decodeSettingsValidationResult`, `decodeSettingsImpactPreview`, `decodeSettingsCommandResult`)
   - WAI-ARIA / 키보드 접근성을 갖춘 `SettingsLayout` 및 11개 전용 워크스페이스 (`CategoryIndexView`, `PreferencesWorkspace`, `ProjectsWorkspace`, `ProjectDetailsWorkspace`, `ModelsWorkspace`, `CostsWorkspace`, `PrivacyWorkspace`, `ConnectorsWorkspace`, `DirectivesWorkspace`, `SchemaWorkspace`, `DiagnosticsWorkspace`, `AdvancedWorkspace`)

6. **Persistent PostgreSQL Repository & Test Suite (`tests/database/section2-postgres.test.ts`)**:
   - `PostgresProjectAdministrationRepository` & `PostgresSettingsRepository` 연결
   - Atomic Project Creation Coordinator, `SELECT ... FOR UPDATE` 부모 행 잠금, `policy_binding` 스키마 정합성 보장
   - `section2-postgres.test.ts` 추가 (프로젝트 원자적 생성, 설정 명령 revision 증가, 재시작 영속성, 롤백 안전성, idempotency key 재사용 불일치 검증)
